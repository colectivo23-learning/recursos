# Recursos Colectivo23

Recursos gratuitos de Colectivo23 (quizzes, diagnósticos, calculadoras y guías), publicados con GitHub Pages.

**Este repositorio es público.** Solo contiene versiones finales y aprobadas, listas para publicar. El trabajo, los borradores y la documentación interna viven en el repositorio privado `recursos-bf-2026`.

## Qué puede ir aquí
- HTML, CSS, JS e imágenes de recursos aprobados.
- Logos oficiales y fuentes públicas.

## Qué nunca va aquí
- Brandbook, borradores, notas internas ni la hoja de Growth.
- Datos de leads o cualquier información personal. Los formularios envían los datos a HubSpot; nada se guarda en este repositorio.
- Claves o tokens privados.

## Estructura
```
index.html                 Portada
assets/                    Logos y archivos compartidos
[codigo-programa]-[recurso]/index.html   Un folder por recurso publicado
```

Ejemplo: `rt01-quiz-pm/` se publica en `https://colectivo23-learning.github.io/recursos/rt01-quiz-pm/`.
